# 英语推进器实验记录

这是一个每天投入30分钟的英语学习工作台原型。记录核实日期：2026-10-26。页面采用深蓝主题，提供手机布局；真实手机端登录和视觉验收尚未完成。

## 已完成的功能

- 14天任务、30/8分钟模式、暂停计时、草稿、完成记录和表达复习；
- 按账号同步学习记录，离线时本地暂存，支持JSON导入导出；
- 剑桥雅思15–21的私有PDF阅读，支持翻页、跳页、缩放；剑20按Test 1–4切换；
- 剑15–18共64段听力，可选择Test/Part、调速和后退10秒。

剑19–21的听力待补。阅读页码、音频播放位置和计时状态保存在当前设备，不随学习记录自动同步。无自动AI评分或收费功能，学习效果尚未验证。

## 代码与资料在哪里

网站源码在Sites管理的独立仓库维护。本操作手册只保存脱敏后的实验记录，不将嵌套源码目录当作公共仓库的一部分。GitHub上的说明更新和网站上线是两个独立操作。

PDF、音频、学习数据、私人网盘路径与访问凭据不加入本仓库。电子资料仅用于当前所有者的私有站点；出售工具前，仍需单独解决多用户授权和资料使用权限。
