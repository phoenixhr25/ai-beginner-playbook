# 案例：物光项目从输出目录迁移到固定项目

## 当时的问题

物光项目位于带日期的 Codex 输出目录：

```text
~/Documents/Codex/2026-09-27/streamlit-2/outputs/wuguang-public
```

用户担心 `.git` 是否丢失、对话压缩是否删除文件，并希望把物光保存为 Codex 固定项目。

## 得到的结论

- 对话压缩只整理聊天上下文，不会删除本地文件或 `.git`。
- `.git` 是隐藏目录，保存提交历史、分支和远程仓库信息。
- 日期目录和 `outputs` 更像临时产物，不便于长期查找和管理。
- GitHub Connector 与本地 Git 是两个独立通道；Connector 无写权限时，本地 Git 仍可能正常推送。

## 实际操作

1. 在 `~/Documents` 下建立 `Projects`。
2. 使用 Finder 将整个 `wuguang-public` 文件夹移动过去。
3. 将文件夹改名为 `wuguang-inventory`。
4. 确认 `.git`、分支、GitHub 远程地址和最新提交仍然存在。
5. 在 Codex 中将新目录添加为项目。
6. 把 Codex 项目名称从 `New project` 改为“物光”。

## 最终位置

```text
~/Documents/Projects/wuguang-inventory
```

## 验证结果

- `.git` 完整保留；
- 分支为 `main`；
- GitHub 远程仓库仍为 `phoenixhr25/wuguang-inventory`；
- 产品文件和文档完整；
- 工作区没有未提交修改；
- Codex 左侧已显示固定项目“物光”。

## 可复用经验

移动 Git 项目时必须移动整个根目录，不能只复制可见文件。迁移后依次检查：路径、`.git`、`git status`、`git remote -v`、最新提交和 Codex 项目绑定。

详细操作见：[Codex 固定项目与 Git 迁移指南](../01-Codex/Codex固定项目与Git迁移指南.md)。
